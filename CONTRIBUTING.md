# Contributing

Use small, reviewed changes. Never submit real user profiles, backups, secrets, chat history, production logs or identity data. Reproduce bugs with synthetic test fixtures. Each patch should include a focused test and a CHANGELOG entry, and should document limitations without overclaiming Windows/GUI behavior. Run `python -m unittest discover -s tests -v`; changes to the PowerShell engine require a genuine Windows PowerShell 7 run, not just a Python test. Do not implement a Codex fork or unsupported private APIs.

Reviewers must check the source code and supply chain before running scripts. Project trademarks belong to their respective holders.
