# Contributing

[Русский](../ru/CONTRIBUTING.md) | [Maintenance](MAINTENANCE.md)

Make focused, reviewable contributions with synthetic test cases. Do not publish user profiles, backups, sessions, credentials or private logs. Use native Codex mechanisms, not a fork.

For source changes run `python -m unittest discover -s tests -v`, `python scripts/check-public-tree.py`, and `python scripts/check-docs.py`. PowerShell changes require a genuine Windows CI run. Edit the matching English and Russian documents in parallel without mixing languages. Use clear natural-language commit titles and state unverified limits explicitly.
