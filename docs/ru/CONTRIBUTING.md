# Участие в проекте

[English](../en/CONTRIBUTING.md) | [Сопровождение](MAINTENANCE.md)

Делайте небольшие проверяемые изменения и синтетические тесты. Нельзя публиковать профили, снимки, сессии, учётные данные или приватные логи. Только штатные механизмы Codex, без форка.

Для кода выполняйте `python -m unittest discover -s tests -v`, `python scripts/check-public-tree.py` и `python scripts/check-docs.py`. Изменения PowerShell требуют настоящей проверки Windows CI. Параллельно обновляйте соответствующие русские и английские документы, не смешивая языки. Пишите понятные сообщения коммитов и явно отмечайте непроверенные ограничения.
