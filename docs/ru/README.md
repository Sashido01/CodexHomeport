# Codex Homeport — русская документация

[English](../../README.md) · [Руководство пользователя](GETTING_STARTED.md) · [Настройка](CUSTOMIZATION.md) · [Безопасность](SECURITY.md) · [Сопровождение](MAINTENANCE.md)

**Codex Homeport** — независимый открытый инструмент для установки официального Codex CLI, локального резервного копирования и консервативного восстановления пользовательских настроек. Проект не является продуктом OpenAI, не заменяет Codex и не изменяет его механизм авторизации.

## Возможности

- Проверка установленного Codex CLI и состояния доступных настроек.
- Запуск **официальной** процедуры установки CLI по явной команде пользователя.
- Создание приватного снимка конфигурации за пределами Git-репозитория.
- Проверка манифеста и SHA-256, просмотр плана восстановления без записи.
- Восстановление после явного подтверждения с резервированием заменяемых файлов.

**Не переносится:** учётная запись, ключи, токены, активные сессии, история диалогов, базы SQLite, данные Codex Desktop, сторонние программы и проекты. Копия настроек **не зашифрована**; не отправляйте её в публичный GitHub.

## Быстрый старт

На Windows 10/11 потребуется PowerShell 7. Из корня репозитория:

```powershell
pwsh -NoProfile -File .\scripts\homeport.ps1 -Action Status
```

На Linux/macOS потребуется Python 3.9+:

```bash
python3 scripts/homeport.py status
```

Подробные команды резервирования, проверки и восстановления приведены в [руководстве](GETTING_STARTED.md). Пользователь сам выбирает расположение проекта и приватных резервных копий.

## Состояние проверки

Проверены изолированные сценарии на Windows PowerShell 7 и Linux. Восстановление реальной учётной записи, сессий Desktop и подключений MCP **не подтверждено**. Исторические результаты — в [журнале испытаний](../VALIDATION.md).
