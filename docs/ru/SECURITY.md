# Границы безопасности

[English](../en/SECURITY.md) | [Описание](README.md)

1. В публичном репозитории, PR, Issues и CI запрещены приватные экспорты, `auth.json`, токены, история диалогов, SQLite, учётные данные, личные логи и сборки Codex.
2. Копии могут содержать секреты внутри `config.toml` или `AGENTS.md`. Копии **не шифруются**. Храните их в приватной папке вне Git. SHA-256 выявляет изменения, но не подтверждает доверенность источника.
3. Восстановление проверяет пути, ограничения размера и контрольные суммы; по умолчанию это dry-run. Для записи нужно явное подтверждение. Старые файлы сохраняются для отката. Сбои питания, параллельная запись и злонамеренный снимок не покрываются гарантией.
4. Состояние Desktop, авторизация и сторонние MCP-серверы не переносятся. Перед запуском проверяйте навыки.
5. Тесты используют синтетические данные и только чтение в CI. Уязвимости сообщайте приватно; не публикуйте реальные ключи.

Техническая модель угроз — в [docs/SECURITY.md](../SECURITY.md).
